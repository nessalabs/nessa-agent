# Project skills

Skills in this folder load for every Claude Code session that opens this
repository, including the project's cloud threads.

## Emil Kowalski's design and motion skills

Copied from [emilkowalski/skills](https://github.com/emilkowalski/skills) at
commit `715c1807e08c497cfd1dc4feb450a2a3300ef2a9` (2026-11-09), unchanged:
`emil-design-eng`, `animate`, `review-animations`, `improve-animations`,
`find-animation-opportunities`, `remove-animations`, `choreograph`,
`animation-performance`, `animation-vocabulary`, `apple-design`, `gestures`,
`write-swift`, `pick-ui-library`, `prototype`, `break-ui`.

Left out because Nessa does not use what they cover: `animate-expo` (React
Native and Expo), `ask-sonner` (the Sonner toast library) and `mobile-native`
(a web app running in a phone browser).

They are copied, not fetched at session start, so a session gets a reviewed,
fixed version. To take a newer upstream version, copy the folders again from a
fresh clone and update the commit above in the same pull request.

On a Mac, `npx skills@latest add emilkowalski/skills -g` installs them for
every repository and for Codex and OpenCode as well; skip the copies here then,
or each skill shows up twice in this repository.
