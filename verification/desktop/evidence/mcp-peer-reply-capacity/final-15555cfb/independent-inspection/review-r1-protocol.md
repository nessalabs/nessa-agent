## Agreement across fields and layers

Authoritative facts traced together: Shared RPC ID/pending receipt/first terminal cause; envelope ordinary permit; captured peer request binding/version; HTTP recovery state and dispatch/closing fence; registered reader ownership and retained SessionClaims cleanup/DELETE. The envelope transfers only message ownership: dropping its permit does not confirm HTTP readiness or an external effect. Queue clone cannot mint a new binding. Captured version cannot be replaced by matching initialization; J22 tests that contradiction while also proving successful current-session ordinary work remains accepted. Busy ordinary calls and successful provisional peer answers are a valid combination and are covered by J21/J22. Overflow/timeout/close/Unauthorized all preserve cleanup ownership while forbidding delayed answer and initialized effects (J23/J25/J26). Closed queue does not fabricate Unconfirmed or replace an earlier end cause. Cancellation frees caller admission and directly cancels local POST independently of remote queue availability.

Inspected boundaries: call/notify/Pending drop → queue → writer dispatch → HTTP request context/retry; incoming JSON/SSE context → reader reply admission → HTTP shutdown → Shared.end → pending outcomes; recovery startup → FIFO handoff → initialized POST/completion commit. There is no persistence/restoration/application/UI mapping added, so no new cross-record agreement proof is needed there. This report does not infer all existing SDK lifecycle correctness from this transport review.
